# Ansible_opdracht
Opdracht
In deze opdracht maak je een Ansible Playbook waarmee je verschillende servers maakt. Het idee is dat er twee servers in het netwerk aanwezig zijn en, dankzij het Playbook, de webserver + database server functionaliteiten krijgen. Zie de onderstaande Playlist:

https://www.youtube.com/playlist?list=PLT98CRl2KxKEUHie1m24-wkyHpEsa4Y70

 

Maak 3 virtuele machines met daarop Linux Server (CLI) distro's geïnstalleerd:

Ansible host
Webserver –> in een onafhankelijke Play wordt een willekeurige PHP-website geüploaded
Database server
Let op! De webserver en database server zijn verschillende distro's. Jouw naam is verwerkt in de SSH key, machine- en accountnaam.

Lever het volgende in:

Een Git-repo met de Playbook, Tasks en Inventory (let op de rechten!);
Dubbele code moet worden vermeden. 
Een video als bewijs dat de Playbook werkt;
Naast de serverrollen, wordt ook de website geüploaded op de webserver;
Jouw naam is zichtbaar in de machine- en accountnaam.
 

Voor hulp met ssh:
https://www.learnlinux.tv/getting-started-with-ansible-02-ssh-overview-setup/

Voor hulp met ansible lees README_ansible in deze folder.
